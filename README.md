# SwiftUI Skills

Backup of Apple SwiftUI agent guidance bundled with Xcode 27 beta, converted from Xcode prompt templates into portable `SKILL.md` directories.

## Skills

- `swiftui-specialist`: SwiftUI best practices and idiomatic patterns.
- `swiftui-whats-new-27`: New APIs, behavior changes, and deprecations in the 2027 Apple platform SDKs.

Each directory contains its entry-point `SKILL.md` and the original supporting Markdown references shipped by Apple.

The guidance remains authored and published by Apple. This repository preserves it for personal backup and agent interoperability.
